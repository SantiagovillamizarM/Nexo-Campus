Actúa como desarrollador de Python y Streamlit y ayúdame a implementar únicamente la primera tarea que me asignaron en una hackatón. Trabaja sobre el repositorio real y explícame lo necesario con palabras sencillas, porque soy principiante.

## 1. Contexto del proyecto

El proyecto se llama CampusOps y corresponde al desafío “El campus bajo presión” de Campuslands.

El equipo tiene cuatro personas y cinco horas para construir un MVP funcional que integre:

- Gestión de espacios y reservas.
- Préstamo y devolución de recursos tecnológicos.
- Gestión de incidencias con ayuda de IA.

La arquitectura acordada es:

UI con Streamlit → Servicios de Python → Repositorios con SQLite.

Los servicios también podrán utilizar un cliente de IA, mediante Ollama o una API autorizada para la jornada. La opción concreta depende de lo que confirme el equipo.

Streamlit llamará directamente a los servicios de Python. No se utilizará FastAPI en esta primera implementación.

## 2. Mi rol y el de mis compañeros

Soy P4: responsable de interfaz y entrega.

El reparto es:

- P1: datos, modelos, carga y limpieza de información, SQLite y persistencia.
- P2: estructura inicial del repositorio y servicios con las reglas de negocio.
- P3: cliente de IA, prompts y validación de sus respuestas.
- P4 —yo—: pantallas de Streamlit, conexión de la interfaz con los servicios, mensajes de carga/éxito/error y, posteriormente, README y guion de demostración.

Mi responsabilidad general incluye crear la interfaz, conectar sus controles con las funciones reales de mis compañeros y comprobar su funcionamiento desde las pantallas.

Sin embargo, esta solicitud se limita al primer paso.

## 4. Qué debes implementar ahora

Construye una aplicación inicial de Streamlit con cuatro pestañas:

1. Inicio.
2. Espacios.
3. Recursos.
4. Incidencias.

Cada pestaña solo necesita:

- Un título claro.
- Un texto breve que indique qué se mostrará allí más adelante.

Por ejemplo, en Espacios puede aparecer “Aquí se mostrarán los espacios y las reservas”.

Las pestañas deben poder abrirse y la aplicación debe ejecutarse sin depender de una base de datos, un modelo de IA ni servicios todavía no disponibles.

Puedes mostrar el nombre CampusOps como título principal.

En esta etapa, “pestañas vacías” significa que todavía no tienen operaciones reales. Los títulos y mensajes informativos son suficientes.

## 5. Python y Streamlit

Utiliza Python y Streamlit para crear la interfaz.

Ten presente que:

- Python es el lenguaje de programación.
- Streamlit es una biblioteca/framework de Python para crear interfaces web.
- El código se escribe en archivos `.py`.
- La aplicación se ejecuta con Streamlit y se visualiza en el navegador.
- Streamlit proporciona títulos, pestañas, botones, formularios y tablas.
- Para este esqueleto basta con sus componentes nativos.

No hace falta añadir HTML, CSS, JavaScript, React ni herramientas adicionales para completar esta tarea.

La apariencia inicial debe ser sencilla, legible y ordenada. No hay un diseño de Figma definitivo seleccionado: anteriormente solo se consultaron referencias. No inventes que existe un diseño aprobado.
